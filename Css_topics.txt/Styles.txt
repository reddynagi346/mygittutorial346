    Topic 4 :: Positions in CSS

    Positions are five types==>
    
    position:Static(Default);

    position: Relative;

    position:Absolute;

    position:Fixed;

    position:Sticky;


    Whenever We can use Position Style we can also use help Parameters like:"top, right, bottom, left"

1). position Relative:
    Example: 
   .box-container{
    border:2px solid red;
    margin-top:250px;
    padding:0px;
   }


    .box1{
     height:200px;
     width:150px;
     background-color:blueviolet;
     display:inline-block;
     position:relative;
     bottom:200px;
     left:300px;
    }

    .box2{
        height:200px;
        width:150px;
        background-color:rgb(43, 168, 226);
        display:inline-block;
       }
  2).Position Absolute:
  Example::
  .box1{
     height:200px;
     width:150px;
     background-color:blueviolet;
     display:inline-block;
     position:absolute;
     z-index: 5;
     
    }

    .box2{
        height:200px;
        width:150px;
        background-color:rgb(43, 168, 226);
        display:inline-block;
        position:absolute;
        z-index:6;
       }
By using this Z-index we can add value of property which ever is highest it will comes on display. Here we can also provide Negative values also(which value is higher can comes on display) 
3). Position Fixed
 By Using this Property we can fix the any content i.e images, logo's etc..
 If we want to place fixed content on right bottom side we can use the following syntax:
 ex==>
 img{
    position:fixed;
    right:0;
    bottom:0;
 }
 4). position Sticky
This property same like as Position Fixed property the major diferance is we can fix where ever we can place it.
it can not cover the background content of the web page.
ex==>
 img{
    position:sticky;
    right:0;
    bottom:0;
 }

 P-SEDUO Elements :
 A CSS pseduo -element is used to style specified part of an element
  We Can use Pseduo Element two "Colons" :: where as Pseduo classes as single "colon" ":"
 Types of the Pseduo-elements==>
   1). ::before
   2). ::after
   3). ::First-letter
   4). ::first-line
   5). ::placeholder

1) ::before==>
    by using this sytle we can add any content in webpage such as images, text ...
     example :
     .text::before{
        background:url();
        width:100%;
     }

2). :: after==>
same as before element but the difference is content will be on end of web page
same syntax instead of after we put in on after

3),4). ::first-letter, ::first-line:: ==>
by using this we can stylew the first letter/line of the content in web page
Syntax:
focus::first-line/first-letter{
    color:blue;

}

5). placeholder
By using this we can style the place holder of the input Element
Syntax:
focus::placeholder{
    color:red;
}

Gradients :
Gradients are like we can add multiple colors of the webpage with smooth transition. there are two types in gradients.
1. linear-gradient
2.radial-gradient


1).linear-gradient:
  in this we can add colors linear from left to right , right to left , top to bottom and bottom to top.
  syntax is 
  background: linear-gradient( to right, color1,color2,color3,.......)
  background: linear-gradient( to left, color1,color2,color3,.......)
  background: linear-gradient( to bottom, color1,color2,color3,.......)
  background: linear-gradient( to top, color1,color2,color3,.......)

 2). Radial-gradient:
  In this we can add colors circle form . syntax of this is::
  background: radial-gradient( circle, color1,color2,color3,.......)
